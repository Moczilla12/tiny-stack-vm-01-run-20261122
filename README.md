A faithful interpreter of make.fun's tiny stack ISA v1 in one `main.ts` (Node 22): 32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, all ten traps with their own exit codes, in the ISA's exact check order. Run: `MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts`.
